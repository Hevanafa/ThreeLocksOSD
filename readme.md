# ThreeLocksOSD

![ThreeLocksOSD preview](./preview.png)

An app to show the lock key status without the 200+ MB bloat

Basically telling you whether the Caps Lock is on or not

## Features

## Usage

1. Download the latest version from the releases page
2. Extract the ZIP
3. Run ThreeLocksOSD.exe
4. Press any lock keys: num lock, caps lock, or scroll lock
